d) Is the given tree a valid BST?

Given tree:

        50
       /  \
     30    70
    / \    / \

❌ Not a valid BST

Why?

Node 65 is in the left subtree of 50, but 65 > 50 (violates BST rule)
Left subtree must contain only values less than 50

👉 Hence, BST property is violated
